## 2. Three Target Tasks & Success Definitions

### Task 1: Debugging Python & Machine Learning Code Errors
* **Current Friction:** Spending 15-20 minutes staring at stack traces (like KeyError or FileNotFoundError) trying to find typos.
* **Done Well Means:** When an error occurs, AI correctly identifies the exact line and structural fix on the first prompt, reducing total debugging time to under 2 minutes.

### Task 2: Summarizing Weekly Technical Research Papers
* **Current Friction:** Reading 20+ pages of heavy academic AI texts takes hours, making it hard to extract actionable metrics.
* **Done Well Means:** AI reduces the text into a 1-page structured bulleted summary without missing any key data metrics, verified by a quick human skim in under 5 minutes.

### Task 3: Writing Explanatory Project Documentation
* **Current Friction:** Writing long markdown summaries for project deliverables takes up valuable coding time.
* **Done Well Means:** AI generates clear, scannable documentation structures based on code inputs with zero generic text, saving 70% of writing time.
