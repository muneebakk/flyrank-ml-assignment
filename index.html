Predicting Click-Through Rate Anomalies Using Temporal Features

Author: FlyRank ML Intern

Abstract (5-Sentence Summary): How can digital platforms effectively locate and prioritize organic search performance anomalies at scale? This paper leverages the public-safe FlyRank search warehouse to model baseline expected click-through rates. By employing engineered textual features alongside historic positional markers, we train a Gradient Boosting model framework. The predictive setup successfully outperforms static moving average baselines, reducing root-mean-squared errors significantly. Consequently, these outputs drive an automated ranked action playbook designed to isolate under-performing assets.

1. Introduction / Problem Statement

Traditional search tracking relies heavily on fixed CTR thresholds, which fail to capture dynamic positional curves. This research addresses that inefficiency by building a predictive validation model to support programmatic meta-content decisions.

2. Data Engine & Transparency

We utilized the FlyRank ML Internship warehouse via remote Hugging Face Parquet streams. All private attributes, including client identities and explicit domain URLs, were stripped out or hashed to guarantee absolute anonymity.

3. Methodology & Evaluation Design

Features were extracted based on query lengths, word counts, and search impressions. To prevent temporal data leakage, a strict time-aware split was executed: historical weeks 6 and 7 were utilized for model optimization training, while week 8 was held back exclusively for future evaluation validation.
